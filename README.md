# सारथी · Saarthi

**Smart Adaptive Assistant for Real-Time Help & Intelligence**

A personal, voice-first AI assistant for Android, inspired by JARVIS and styled after ancient Indian craft: a golden chariot-wheel core on palm-leaf parchment by day and a starry indigo sky by night.

## Get the app

Every push to `main` is built in the cloud by GitHub Actions. Open the [latest release](../../releases/latest) on your phone, download the `.apk` file, and open it to install.
